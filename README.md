2D платформер на Unity + C#, в котором игрок управляет персонажем, способным переключаться между четырьмя стихиями. Каждая стихия имеет уникальные способности, позволяющие преодолевать препятствия и ускорять прохождение уровней.

---

## Система стихий

Центральная механика игры — переключение между четырьмя стихиями.

### Ветер
- Двойной прыжок
- Медленное падение
- Рывок

---

### Земля
- Ускоренное падение

---

### Огонь
- Суперскорость
- Установка чекпоинта для воскрешения

---

### Вода
- Персонаж превращается в слизня
- Проход через узкие места

---

## Дизайн уровней

Каждый уровень строится на двух принципах:

**Ограничение** — уровень нельзя пройти только одной стихией или просто прыжком.

**Комбинация** — решение представляет собой последовательность переключений между стихиями.

---

## Прогрессия

```
Обучение:   1 стихия → 2 стихии → комбинации
Уровни:     каждый вводит новую идею + комбинирует старые
Сложность:  растёт через количество шагов, планирование и точность
```

## Сборка проекта

### Требования

- [Unity Hub](https://unity.com/download)
- Unity **2021.3 LTS** или новее
- Git

---

### 📦 Сборка .exe

1. Запусти проект в Unity Hub и открой меню **File → Build Profiles**

2. В списке платформ выбери **Windows/Mac/Linux** и нажми **Switch Platform** (если платформа ещё не выбрана)

3. Нажми **Build**

4. Выбери папку назначения, Unity создаст `.exe` файл и другие необходимые файлы рядом с ним
